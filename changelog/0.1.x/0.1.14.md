# 0.1.14 — 2026-07-10

## Added

- **`eurostat_search_datasets` cursor pagination** — new optional `cursor` input; `limit` is now the page size (previously a hard ceiling on total results). Enrichment adds `nextCursor` (opaque, omitted on the last page) and `truncated` (more matches remain); `totalMatches` now reports the full count across all pages. Built on the framework's `paginateArray` primitive ([#16](https://github.com/cyanheads/eurostat-mcp-server/issues/16)).
- **`nextStep` output field** on `eurostat_search_datasets` and `eurostat_browse_themes` — a suggested follow-up call (e.g. pointing at `eurostat_get_dataset_info`), rendered as a "Next step" line in `format()` text; omitted when there's no clear follow-up, such as an empty theme folder ([#13](https://github.com/cyanheads/eurostat-mcp-server/issues/13)).
- **`skills/api-linter` `definition-invalid` rule** — flags a `null`/`undefined` entry in a `tools`/`resources`/`prompts` array passed to `validateDefinitions()` instead of crashing the lint run.
- **Supply chain** — adds `.gitattributes` (LF normalization, binary-asset markers, `linguist-generated` tags for `bun.lock`/`CHANGELOG.md`/`docs/tree.md`) and `.github/SECURITY.md` (vulnerability reporting policy).
- **`bunfig.toml` install guard** — `minimumReleaseAge` blocks installing package versions published less than 3 days ago (`@cyanheads/mcp-ts-core` excluded, adopted same-day), with `@socketsecurity/bun-security-scanner` wired as the install-time package scanner; `scripts/devcheck.ts`'s outdated-dependency check now treats a guard-held row (Update equals Current, `*`-flagged) as expected rather than a failure.

## Changed

- **Tool descriptions and docs** — dropped the hardcoded "8,933 datasets" and "11 top-level themes" figures from `eurostat_search_datasets`, `eurostat_browse_themes`, the server's `instructions` string, and `docs/design.md`; both counts drift upstream and were already stale ([#19](https://github.com/cyanheads/eurostat-mcp-server/issues/19)).
- **`@cyanheads/mcp-ts-core`** `^0.10.9` → `^0.10.14` — adopts `ctx.state.getMany(keys)`, the `ctx.elicit.url(message, url)` external-link form, explicit `ctx.enrich` helpers (`.notice()`/`.total()`/`.echo()`/`.truncated()`), and the `ctx.content` non-text block collector (`.image()`/`.audio()`).
- **Skills** — re-synced from the framework; 12 `metadata.version` bumps propagate body drift (`add-tool`, `api-canvas`, `api-linter`, `api-utils`, `api-workers`, `code-simplifier`, `design-mcp-server`, `git-wrapup`, `orchestrations`, `polish-docs-meta`, `release-and-publish`, `techniques`).
- **`Dockerfile`** — pins `oven/bun:1.3` → `1.3.14` in both stages, adds BuildKit cache mounts (`--mount=type=cache,target=/root/.bun/install/cache`) around every `bun install`, and adds `--ignore-scripts` to the build-stage install.

## Fixed

- **`eurostat_search_datasets` multi-word queries** — the query is now tokenized on whitespace and every token must match (AND), case-insensitively, across a combined `label + themePath + code` haystack, replacing a single substring match against the label alone; queries like "business demography NUTS 3" or "regional economic accounts" now resolve ([#14](https://github.com/cyanheads/eurostat-mcp-server/issues/14)).
- **`eurostat_browse_themes` root browse** — `findRootChildren` now unions the depth-1 children of every depth-0 TOC folder root instead of only the first, so themes under a second root (e.g. `tb_eu`, `cc` under "Cross cutting topics") are reachable from a root-level browse ([#20](https://github.com/cyanheads/eurostat-mcp-server/issues/20)).
