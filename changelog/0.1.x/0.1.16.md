# 0.1.16 — 2026-08-03

## Added

- **`EUROSTAT_TOC_CACHE_TTL_MS`** — configures how long the catalogue TOC cache stays valid before the next `eurostat_search_datasets`/`eurostat_browse_themes` call refreshes it; defaults to `43200000` (12 hours), matching Eurostat's twice-daily update cadence ([#23](https://github.com/cyanheads/eurostat-mcp-server/issues/23)).
- **`.mcpb` bundle** — the clean step now also strips platform-specific `@duckdb/node-bindings-*` native binaries, keeping the bundle portable across platforms and under the registry size cap.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.10.14` → `^0.11.1` — adopts the `fetchWithTimeout` error-data field rename (`responseBody` → `body`) and the new `expectedStatuses` option in `eurostat-data-service.ts`.
- **Catalogue TOC caching** — the in-memory TOC cache now expires after `EUROSTAT_TOC_CACHE_TTL_MS` instead of living for the process lifetime; concurrent callers past the TTL share one in-flight refresh, and a failed refresh serves the last loaded cache and holds the next attempt off for 60 seconds ([#23](https://github.com/cyanheads/eurostat-mcp-server/issues/23)).
- **`eurostat_search_datasets` result set** — matches are deduplicated by dataset code before pagination, so a code Eurostat files under multiple TOC branches is counted and returned once, keeping its first matching placement as the canonical `themePath` ([#26](https://github.com/cyanheads/eurostat-mcp-server/issues/26)).
- **`eurostat_search_datasets` / `eurostat_browse_themes`** now advertise `annotations.openWorldHint: true`, matching their live Catalogue API dependency ([#29](https://github.com/cyanheads/eurostat-mcp-server/issues/29)).
- Skills re-synced from the framework (12 files).

## Fixed

- **`eurostat_search_datasets` whitespace-only query** — now rejected at the input schema (a `\S` pattern on `query`); the service also treats an empty token list as zero matches rather than matching the full catalogue ([#24](https://github.com/cyanheads/eurostat-mcp-server/issues/24)).
- **`eurostat_search_datasets` cross-query cursors** — a cursor is now bound to the normalized query and the TOC snapshot that produced it. A cursor presented with a different query, a malformed cursor, or one issued against a since-refreshed catalogue is rejected as the new `invalid_cursor` contract instead of silently paging a different result set ([#28](https://github.com/cyanheads/eurostat-mcp-server/issues/28), [#23](https://github.com/cyanheads/eurostat-mcp-server/issues/23)).
