# 0.10.1 — 2026-10-22

## Changed

- **Read limits** clamp positive integer previews to 500 and first-page searches to 100 with a notice, log and counter; `EUROSTAT_CLAMP_LIMITS=false` restores rejecting maximum schemas. ([#77](https://github.com/cyanheads/eurostat-mcp-server/issues/77))
- **Dataframe canvas** defaults to `duckdb`; set `CANVAS_PROVIDER_TYPE=none` for inline-only reads. The portable `.mcpb` bundle sets `none` because it excludes native bindings.

## Fixed

- **Request deadlines** bound retries, backoff and body consumption by each operation's configured allowance, preserving caller cancellation and separate metadata/bulk budgets. ([#72](https://github.com/cyanheads/eurostat-mcp-server/issues/72))
- **SQL cells** render as lossless JSON on the text surface, preserving nested values and distinguishing strings from nulls. ([#74](https://github.com/cyanheads/eurostat-mcp-server/issues/74))
- **SQL response size** applies 64,000 bytes per serialized surface, including enrichment, between complete rows; at least one row survives even if oversized. Cuts disclose `truncated` and deterministic SQL paging that advances by actual `rowCount`. ([#75](https://github.com/cyanheads/eurostat-mcp-server/issues/75))
- **Bulk byte budget** retains complete observations within the allowed decoded prefix; an unusable prefix fails as `byte_budget_exceeded` with narrowing guidance. `bytesRead` never exceeds the configured budget. ([#76](https://github.com/cyanheads/eurostat-mcp-server/issues/76))
