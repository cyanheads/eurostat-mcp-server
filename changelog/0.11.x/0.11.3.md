# 0.11.3 — 2026-11-08

## Added

- **`emptyValues`** on `eurostat_query_dataset` and `eurostat_download_dataset`: values the dataset has that the match carries no cell for, under `geo_level` every code of that level with none. A notice names them; the download omits the field when the transfer was cut short ([#96](https://github.com/cyanheads/eurostat-mcp-server/issues/96)).
- **`retry_deadline_exceeded`** on `eurostat_query_dataset`, carrying `deadlineMs`, `elapsedMs` and `retryAttempts`, with a hint built from whether response headers had arrived ([#98](https://github.com/cyanheads/eurostat-mcp-server/issues/98)).
- **`code_prefix`** on `eurostat_get_dimension_values` keeps values whose code starts with the text and is bound in the cursor. One holding `.` that matches nothing advises the code with the dots removed on `DS-*`, a `filter` search elsewhere ([#102](https://github.com/cyanheads/eurostat-mcp-server/issues/102)).
- **`level` column** on a `geo` list staged by `eurostat_get_dimension_values` (NULL for a code with no NUTS level). Staged without `geo_level`, the table holds every level; a notice and `content[]` warning appear when it holds more rows than the level listed inline ([#99](https://github.com/cyanheads/eurostat-mcp-server/issues/99)).
- **`matchedValues`** on `eurostat_search_datasets` rows: when no dataset's own text holds every word, a query of up to 10 distinct words is matched against dimension value labels, listing the values carrying the most query words first. The index is built in the background from the per-dataset metabase and the global codelists (about 30 MiB retained); a malformed download fails the load instead of indexing part of it. A cursor over these rows is refused once the index refreshes, and a `no_match` hint says when dimension value labels were not searched: while the index loads, or for more than 10 distinct words ([#103](https://github.com/cyanheads/eurostat-mcp-server/issues/103)).

## Changed

- **`absentCellCount`** on both data tools counts periods inside each frequency's span, from its first to its latest period with a cell; periods outside it are named in a notice. The last-N notice advises a larger `last_n_periods` only when every empty selected period follows the slice's latest period with a cell, naming the exact N for a slice of one frequency and a `since_period`/`until_period` range ending at that period; when the slice starts later, it says so instead. The `no_results` hint and the `last_n_periods` description advise a `since_period`/`until_period` range in place of `until_period` alone, which selects every period up to it ([#97](https://github.com/cyanheads/eurostat-mcp-server/issues/97)).
- **`eurostat_search_datasets`** ranks matches in tiers: a label holding the query as a phrase that begins at a word start, then a label or code holding every word, then a theme breadcrumb only. The cursor carries the snapshot's entry count ([#101](https://github.com/cyanheads/eurostat-mcp-server/issues/101)).
- **`invalid_dimension`** on both data tools names every unknown filter key (`unknownDimensions`, `dimensionOrder`). The query's `no_results` lists each unmatched dimension's codes and labels (`validValues`) when it has at most 25, otherwise its total plus a value search ([#104](https://github.com/cyanheads/eurostat-mcp-server/issues/104)).
- **`+` in a filter value** is OR on both data tools (`["DE+FR"]` is `["DE", "FR"]`); the query reports a value holding `.` as unmatched, with advice ([#100](https://github.com/cyanheads/eurostat-mcp-server/issues/100)).
- **`EUROSTAT_BULK_TIMEOUT_MS`** also bounds each download that builds the dimension value index.
- **`skills/eurostat-guide`** 1.1.1 → 1.2.0.

## Fixed

- **`eurostat_download_dataset`** rejects a filter value holding `.` as `invalid_dimension` before any request, with per-value advice (the code with the dots removed on `DS-*`, a value search elsewhere): such a value never named a Eurostat code, and in the positional key it added a position.
- **`eurostat_download_dataset`** declares `retry_deadline_exceeded` (Timeout), which it could already raise: the transfer outlasting `EUROSTAT_BULK_TIMEOUT_MS`, or a filtered download's structure read outlasting the request deadline. It carries `deadlineMs` and `elapsedMs`, and the hint names which read ran out.
- **`eurostat_search_datasets`** `no_match` checks at most the first 32 distinct words, so the dead-word check and per-word counts have a fixed bound.
- **Search queries** count a repeated word once.
- **Search cursor-mismatch hint** renders the query as a literal.
- **Download hints** offer an unfiltered download only off `DS-*`: the `filter_arity` hint, and the `upstream_fault` message and hints for a structure read that answered HTTP 501 or returned a structure no filter key can be built from.
- **`geo_level`** descriptions and docs no longer state fixed level counts.
- **Canvas IDs and table names** in notices and `content[]` render as code spans.
- **Counts** in messages, notices and `content[]` are formatted `en-US` whatever the host locale.
- **XML entities** are decoded by one shared decoder: bulk fault strings also decode numeric and any-case references, and a reference past U+10FFFF is kept as written.
- **`eurostat_search_datasets` and `eurostat_browse_themes`** fail as `upstream_fault` naming the status when the catalogue's table-of-contents read returns a non-outage HTTP status: `retryable: true` for a 408 or 429 that outlasts the retries, `retryable: false` for any other, such as a 404.
- **`eurostat_get_dimension_values`** notice for a `filter` that matched nothing within a `geo_level` names the route: another `geo_level` searches that level's codes.
