# 0.6.1 — 2026-08-21

## Changed

- **`@cyanheads/mcp-ts-core` 0.12.3 adoption** serves MCP protocol revision 2026-07-28 alongside existing clients, advertises strict tool inputs and the error output envelope, adds stateful HTTP replay, and records failures across output validation, formatting, and enrichment.
- **Request contexts** now pass directly into framework fetch, retry, and cursor helpers without compatibility casts.
- **TypeScript and Vitest configuration** typechecks `src/` and `tests/` together while keeping build emission scoped to `src/`, with named unit, smoke, integration, and fuzz projects.
- **Runtime packaging** pins Bun 1.4.0 and omits optional framework peers from the production image while retaining the DuckDB canvas binding as a direct dependency.
- **Project guidance and metadata** syncs the framework 0.12.x skills, MCP SDK v2 conventions, community health files, bundle checks, and security contact.

## Fixed

- **`eurostat_download_dataset` inline previews** report `truncated`, `shown`, and `cap` through enrichment whenever rows are omitted, keeping `structuredContent` and `content[]` aligned.
- **Directory tree generation** applies directory-only ignore patterns to directories, so ignored agent and workspace directories stay out of the generated tree.
