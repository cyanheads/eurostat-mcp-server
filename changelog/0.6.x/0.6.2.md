# 0.6.2 — 2026-08-30

## Added

- **`eurostat_query_dataset.preview_limit`** returns a deterministic 1–500-row inline prefix (default 50) while full-match totals and the 5,000-row staging threshold remain independent ([#39](https://github.com/cyanheads/eurostat-mcp-server/issues/39)).

## Changed

- **Dataset metadata and dimension values** now come from each dataset's SDMX dataflow descendants and content constraint, including complete available `time` values ([#44](https://github.com/cyanheads/eurostat-mcp-server/issues/44)).
- **Canvas-producing responses** direct callers to inspect `eurostat_dataframe_describe` before querying the returned table ([#42](https://github.com/cyanheads/eurostat-mcp-server/issues/42)).

## Fixed

- **`NO_RESULTS` and geo slices** distinguish empty valid queries from missing datasets, report the effective geo level, and expose a recovery hint for conflicting query parameters ([#37](https://github.com/cyanheads/eurostat-mcp-server/issues/37), [#38](https://github.com/cyanheads/eurostat-mcp-server/issues/38), [#41](https://github.com/cyanheads/eurostat-mcp-server/issues/41)).
- **HTTP 413 error bodies** are classified as non-retryable asynchronous responses before retry handling ([#44](https://github.com/cyanheads/eurostat-mcp-server/issues/44)).
