# 0.6.5 — 2026-09-21

## Changed

- **`canvas_id`** on `eurostat_query_dataset`, `eurostat_download_dataset`, `eurostat_dataframe_describe`, and `eurostat_dataframe_query` now uses mcp-ts-core 0.13.5's `CanvasIdSchema` (`pattern: ^[A-Za-z0-9_-]{10}$`), so a malformed id is rejected at argument validation with `reason: invalid_arguments` instead of reaching the canvas lookup, or being silently ignored on the two staging tools when nothing is staged. Well-formed ids behave as before.
- **Argument rejections** carry `data.reason: "invalid_arguments"` and a schema-derived `Recovery:` hint (mcp-ts-core 0.13.3).
- **Tool arguments pass a pre-validation step** (0.13.4): a case-variant key such as `datasetCode` is rewritten to its declared key when it uniquely matches one, the client-added `_meta`, `tool_call_description`, and `toolCallId` keys and any other `_`-prefixed key are dropped, and a `filters` value sent as a JSON-stringified array is parsed back into an array. Any other undeclared key is still rejected.
- **A DuckDB conversion or out-of-range error** in `eurostat_dataframe_query` SQL now comes back as a `ValidationError` with `reason: "sql_execution_error"`, instead of a `DatabaseError` (0.13.4).
- **Tool error text** in `content[]` now closes with `(reason <reason>)`, adding ` · not retryable` or ` · retryable` when the error carries a `retryable` flag; `structuredContent` is unchanged (0.13.5).
- **README documents `MCP_SESSION_MODE`**, and an integration test pins both cases (#43). With `MCP_SESSION_MODE` unset the server runs stateless, the default `createApp()` declares; an explicitly set `MCP_SESSION_MODE` still overrides it.
- **Repo scaffolding synced** to the current framework template: `.github/workflows/codeql.yml` added, framework skills and `lint-mcp.ts` re-synced, Dockerfile comments and issue-form text updated. The ten error reasons produced below the handler carry mcp-ts-core 0.13.6's `thrownBy: 'service'` lint marker: `canvas_not_found` on all four canvas tools, `missing_table` on `eurostat_dataframe_query`, and `not_found`, `invalid_dimension`, `filter_arity`, `async_queued`, and `upstream_fault` on `eurostat_download_dataset` (lint-only metadata; the advertised error contract is unchanged).
