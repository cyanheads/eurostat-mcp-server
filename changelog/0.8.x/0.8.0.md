# 0.8.0 — 2026-09-25

## Added

- **Comext `DS-*` collections on every tool** ([#46](https://github.com/cyanheads/eurostat-mcp-server/issues/46)). A dataset code starting `DS-`, in any case, is routed to the Comext dissemination host: detailed trade by CN8, HS, SITC, BEC and CPA, and PRODCOM. Comext entries report `lastUpdated` but no period coverage or observation count.
- **Comext dataflows in the catalogue** ([#46](https://github.com/cyanheads/eurostat-mcp-server/issues/46)). `eurostat_search_datasets` and `eurostat_browse_themes` merge the Comext dataflow list into the table of contents, under `ext_go_detail` (in `ext_go`) and `prom` (in `icts`); a failed Comext fetch leaves the catalogue answering from the table of contents alone.
- **`canvas_id` on `eurostat_get_dimension_values`** ([#50](https://github.com/cyanheads/eurostat-mcp-server/issues/50)) stages the dimension's whole value list as a `code` / `label` table on that canvas, returned as `canvasId` / `tableName` / `stagedRowCount`, to label a download's code columns through a join. The tool never starts a canvas; an unknown or expired `canvas_id` fails as `canvas_not_found`.
- **`valueText` on `eurostat_query_dataset` observations, and `obs_value_text` on `DS-*` staged tables** from either data tool, holding a value Eurostat published as text (PRODCOM's unit `KG`). PRODCOM's `:C` decodes to `confStatus` / `conf_status` `C`.
- **`EUROSTAT_COMEXT_BASE_URL`** (default `https://ec.europa.eu/eurostat/api/comext/dissemination`) and **`EUROSTAT_METADATA_TIMEOUT_MS`** (default `120000`), the timeout for one dataset's SDMX dataflow structure: 23 MB for `DS-045409`.

## Changed

- **Breaking: `eurostat_get_dimension_values` returns at most 2,000 values inline** ([#50](https://github.com/cyanheads/eurostat-mcp-server/issues/50)), with `truncated`, `shown`, `cap`, and a `notice` saying where the rest are; `totalCount` still counts every value. Seven main-host lists are cut: `time` on `ert_bil_eur_d`, `ert_h_eur_d` and `irt_euryld_d`, and `airp_pr` on `avia_par_uk`, `avia_par_de`, `avia_par_it` and `avia_par_es`. Pass `canvas_id` to stage the full list.
- **Breaking: `eurostat_download_dataset` maps SDMX fault 413 to non-retryable `extraction_too_big`**, not `upstream_fault`, on either host. The hint names the dataset's dimensions the request left unfiltered.
- **Breaking: `eurostat_get_dataset_info` and `eurostat_get_dimension_values` no longer declare `async_response`; both declare `upstream_fault`** ([#58](https://github.com/cyanheads/eurostat-mcp-server/issues/58)) for a structure or content constraint the server cannot read.
- **Breaking: a text cell on `eurostat_query_dataset` returns `value: null` plus `valueText`**, rather than failing the call's output validation.
- **`eurostat_query_dataset`'s `async_response` hint names the dataset's own unfiltered dimensions**, and the message carries Eurostat's `EXTRACTION_TOO_BIG` label for an HTTP-413 refusal.
- **Dataset metadata is cached per dataset for an hour**, within a 64 MiB budget, so repeat `eurostat_get_dataset_info` and `eurostat_get_dimension_values` calls skip the structure download; a failed read is not cached.
- **Tool descriptions and server instructions** state where the Comext and main-host catalogues end ([#45](https://github.com/cyanheads/eurostat-mcp-server/issues/45)). A query naming a `DS-*` code on neither list, such as the legacy `DS-056120`, fails `no_match` saying the collection is not disseminated.

## Fixed

- **A filtered `eurostat_download_dataset` no longer fails on datasets whose latest period exceeds Eurostat's 5,000,000-row extraction limit** ([#57](https://github.com/cyanheads/eurostat-mcp-server/issues/57)) (`earn_ses_annual`). Key order is read from the dataset's structure definition instead of a one-period observation request.
- **An empty `eurostat_download_dataset` fails `no_results` without creating or touching a canvas** ([#56](https://github.com/cyanheads/eurostat-mcp-server/issues/56)); it previously staged a 0-row table on a fresh or caller-supplied canvas.
- **Cancelling one catalogue or metadata call no longer aborts the shared load** other concurrent callers are waiting on.
